# DIYON GEORGE — Cinematic Director & Screenwriter Portfolio

> *"The most personal is the most creative."* — Martin Scorsese  
> *"...and I'm damn personal about cinema."*

An award-winning, festival-grade web portfolio application created for **Diyon George**—Screenwriter, Film Director, Narrative Architect, and passionate cinephile. Built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and a zero-dependency **Web Audio API Sound Engine**.

---

## 🎬 Creative Philosophy & Visual Identity (Midnight Noir)
- **Palette**: Obsidian Black (`#050507`), Warm Projector Gold (`#D4AF37`), Midnight Charcoal (`#121218`), Script Off-White (`#E2E8F0`).
- **Texture**: Procedural 35mm Celluloid Film Grain Canvas (real-time procedural jitter at 14 FPS).
- **Typography**: Authentic `Courier Prime` Screenplay font paired with `Cinzel` display and `Plus Jakarta Sans`.
- **Viewfinder HUD**: Real-time Director's Viewfinder HUD with interactive Aspect Ratio shifts (`Full`, `2.39:1 Scope`, `1.85:1 Flat`, `4:3 Academy`).
- **Soundscape Engine**: Pure Web Audio API acoustic synthesis featuring:
  - 35mm Projector Motor & Optical Track Hum (low-frequency resonance)
  - Slate Clapboard Snap (crisp wooden transient impact)
  - Film Reel Sprocket Clicks (subtle mechanical ticks on navigation)
  - Typewriter Keystroke feedback

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone or navigate to the repository directory
cd DIYON

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
